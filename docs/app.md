# 앱으로 보기

세계사 정주행은 휴대폰과 컴퓨터에 **앱처럼 설치**할 수 있어요. 앱 스토어를 거치지 않고, 이 사이트에서 바로 설치해요. 설치하면 홈 화면 아이콘으로 열리고, 주소창 없이 책만 보여요.

## 기기별 설치 방법

| 기기 | 방법 |
|---|---|
| 안드로이드 (크롬, 삼성 인터넷) | 위 **앱 설치** 버튼을 눌러요. 버튼이 안 보이면 오른쪽 위 메뉴(⋮) → **앱 설치** 또는 **홈 화면에 추가** |
| 아이폰·아이패드 (사파리) | 아래쪽 **공유** 버튼(네모에 위 화살표) → **홈 화면에 추가** → **추가** |
| 컴퓨터 (크롬, 엣지) | 위 **앱 설치** 버튼을 누르거나, 주소창 오른쪽의 설치 아이콘(모니터에 아래 화살표)을 눌러요 |

## 인터넷 없이 읽기

한 번 연 페이지는 기기에 저장돼서, 인터넷이 끊겨도 다시 열 수 있어요. 비행기나 지하철에서 읽으려면 아래 버튼으로 **책 전체를 미리 저장**해 두세요. 약 160쪽이고, 몇십 초쯤 걸려요.

## 자주 묻는 것

- **돈이 드나요?** 아니요. 무료이고 가입도 없어요.
- **새 페이지가 생기면?** 인터넷이 연결된 상태로 열면 새 내용을 자동으로 받아요.
- **지우려면?** 다른 앱처럼 홈 화면 아이콘을 길게 눌러 삭제하면 돼요.
