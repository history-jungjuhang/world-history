# 앱으로 보기

## 기기별 설치 방법

지금 쓰는 브라우저의 방법이 맨 위에 표시돼요.

<div class="wh-guides" markdown>

<div class="wh-guide" data-guide="android-chrome" markdown>
### 안드로이드 크롬
1. 위의 **앱 설치** 버튼을 눌러요.
2. 버튼이 안 보이면 오른쪽 위 메뉴(⋮) → **앱 설치** 또는 **홈 화면에 추가**를 눌러요.
</div>

<div class="wh-guide" data-guide="samsung" markdown>
### 삼성 인터넷
1. 위의 **앱 설치** 버튼을 눌러요.
2. 버튼이 안 보이면 아래쪽 메뉴(≡) → **현재 페이지 추가** → **홈 화면**을 눌러요.
</div>

<div class="wh-guide" data-guide="ios" markdown>
### 아이폰·아이패드 (사파리)
1. 아래쪽(아이패드는 위쪽)의 **공유** 버튼(네모에 위 화살표)을 눌러요.
2. 목록을 내려 **홈 화면에 추가**를 누르고, 오른쪽 위 **추가**를 눌러요.
3. 크롬 등 다른 앱으로 보고 있다면 사파리에서 이 페이지를 열어 주세요.
</div>

<div class="wh-guide" data-guide="desktop-chrome" markdown>
### 컴퓨터 크롬·엣지
1. 위의 **앱 설치** 버튼을 눌러요.
2. 또는 주소창 오른쪽의 설치 아이콘(모니터에 아래 화살표)을 눌러요.
</div>

<div class="wh-guide" data-guide="mac-safari" markdown>
### 맥 사파리
1. 메뉴 막대의 **파일** → **Dock에 추가**를 눌러요(macOS 소노마 이상).
</div>

<div class="wh-guide" data-guide="firefox other" markdown>
### 파이어폭스와 그 밖의 브라우저
1. 앱 설치를 지원하지 않는 브라우저가 많아요. 크롬, 엣지, 삼성 인터넷, 사파리 중 하나로 이 페이지를 열어 주세요.
2. 설치하지 않아도 이 사이트를 즐겨찾기해 두면 똑같이 읽을 수 있어요.
</div>

</div>

## 인터넷 없이 읽기

한 번 연 페이지는 기기에 저장돼서, 인터넷이 끊겨도 다시 열 수 있어요. 비행기나 지하철에서 읽으려면 아래 버튼으로 **책 전체를 미리 저장**해 두세요. 약 160쪽이고, 몇십 초쯤 걸려요.

## 자주 묻는 것

- **돈이 드나요?** 아니요. 무료이고 가입도 없어요.
- **새 페이지가 생기면?** 인터넷이 연결된 상태로 열면 새 내용을 자동으로 받아요.
- **지우려면?** 다른 앱처럼 홈 화면 아이콘을 길게 눌러 삭제하면 돼요.
