# 오늘의 세계가 어떻게 생겼는지 알려 주는 책

첫 인류가 아프리카를 떠난 때부터 냉전이 끝난 1991년까지 따라가요.
유럽만이 아니라 아시아, 아프리카, 아메리카, 이슬람 세계를 고르게 다뤄요.
어려운 말은 빼고, 내용 수준은 낮추지 않았어요.
